\# IgnisVision Backend



FastAPI backend for the IgnisVision thermal anomaly monitoring platform.



\## Current Features



\- FastAPI REST API

\- NASA FIRMS MODIS thermal anomaly data

\- India geographic filtering

\- Real-time FIRMS data retrieval

\- Anomaly confidence

\- Satellite and instrument information

\- FRP and brightness

\- Acquisition date and time

\- Day/night information

\- Individual anomaly lookup

\- Anomaly count

\- Health check

\- Frontend integration over LAN



\## Requirements



\- Python 3

\- NASA FIRMS API key

\- Internet connection
